# Website Design & Development Guidelines

This project uses dedicated design, UI/UX, and anti-AI-slop skills to build high-craft, distinctive, and accessible web experiences.

## Active Skills & Rules
When designing, building, or reviewing UI code:
1. **Art Direction & Taste**: Use `design-taste-frontend` and `frontend-design`. Ground styling and layouts directly in the subject matter and narrative, avoiding generic templates.
2. **Anti-Slop Standards**: Follow `avoid-ai-design` and `hallmark`. Actively reject 1st-order AI tells (e.g., purple/indigo gradients, default Inter font everywhere, centered 3-card feature grids) and 2nd-order tells (e.g., cliché cream-and-terracotta, dark mode with acid green accent, decorative numbered tags `01 / 02 / 03`).
3. **UX & Accessibility**: Follow `web-design-guidelines` for WCAG contrast compliance, responsive behavior, touch targets, and keyboard navigability.
4. **Interaction & Motion Craft**: Apply `emil-design-eng` and `animate` for fluid, physics-grounded transitions and micro-interactions. Test edge cases with `break-ui`.
